# Proposal

## Why

С `diff_mode = "commits"` вкладка PR открывает `origin/<target>..HEAD`. В этом режиме обе стороны diff — буферы `diffview://<root>/.git/<sha>/<path>`, и LSP к ним не подключается: gopls принимает только URI со схемой `file://`. LSP на правой стороне вкладки PR (файл рабочего дерева) — обязательное условие. Режим `"commits"` его нарушает, и включить такой режим можно одной опцией. Ускорение первого открытия файла (около 169 мс → 68 мс) складывалось в основном из того, что в этом режиме не запускаются LSP и пользовательские хуки буфера. Это и есть то поведение, от которого нельзя отказываться.

## What Changes

- **BREAKING**: опция `setup({ diff_mode = ... })` удаляется. Вкладка PR всегда открывается как `:DiffviewOpen origin/<target>`: справа — файлы рабочего дерева (с влитой целевой веткой), слева — вершина целевой ветки. Значение `"commits"`, переданное в `setup`, больше ни на что не влияет.
- Уходит ветвление по `diff_mode` и связанные с ним комментарии в `open_diffview`.
- Принятие suggestion по-прежнему записывает файл, если его буфер не показан ни в одном окне. Так бывает, когда suggestion принят из PR Info, а файл не открыт. Меняется только обоснование в комментарии: теперь оно не ссылается на режим `"commits"`.
- В README и CLAUDE.md убираются упоминания `diff_mode`.

Вне объёма изменения:
- `:BBPRSinceLastView`. Это отдельный Diffview двух коммитов, и рабочее дерево он не показывает по своей природе.
- Ускорение первого открытия файла в режиме рабочего дерева.
- Конфигурация пользователя (`~/.config/nvim/lua/plugins/bb.lua`). Строка `diff_mode = "commits"` оттуда удаляется вручную.

## Capabilities

### New Capabilities

- `pr-tab-diff-view`: что показывают стороны diff во вкладке PR. Правая сторона — файл рабочего дерева, к нему подключается LSP, его можно редактировать. Левая — вершина целевой ветки.

### Modified Capabilities

- `pr-diff-stats`: из требования «Строка статистики в PR Info» убирается оговорка «в любом режиме diff вкладки», потому что режим теперь один.

## Impact

- `lua/bb_pr/init.lua`:
  - конфигурация по умолчанию — удалить `diff_mode` и его описание;
  - `open_diffview` — всегда `rev = "origin/" .. to_ref`;
  - принятие suggestion — комментарий у записи скрытого буфера.
- `README.md` — абзац «PR tab diff mode», упоминание `diff_mode` в описании строки `Changes:`.
- `CLAUDE.md` — фраза про `diff_mode = "commits"` в разделе «Line numbers».
- Первое открытие ещё не посещённого файла PR у пользователей с `"commits"` станет медленнее (около 169 мс вместо 68 мс при полной конфигурации пользователя).
