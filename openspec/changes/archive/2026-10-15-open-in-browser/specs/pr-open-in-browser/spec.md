# Spec Delta

## Purpose

Открывает в веб-интерфейсе Bitbucket PR, файл PR со строкой или комментарий PR, который пользователь видит в плагине. Так можно перейти к тому же месту в браузере без ручного поиска.

## ADDED Requirements

### Requirement: Контекстное открытие в браузере
Команда `:BBPRBrowse` без аргумента SHALL открывать в браузере самый конкретный объект под курсором в таком порядке: комментарий, затем файл PR (со строкой, если она известна), затем PR. Объект определяется по месту вызова согласно требованиям ниже.

#### Scenario: Курсор на комментарии в PR Info
- **WHEN** пользователь в PR Info ставит курсор на строку комментария и вызывает `:BBPRBrowse`
- **THEN** в браузере открывается этот комментарий, а не PR

#### Scenario: Курсор в шапке PR Info
- **WHEN** пользователь в PR Info ставит курсор на строку `Title:` и вызывает `:BBPRBrowse`
- **THEN** в браузере открывается PR

#### Scenario: Курсор в diff-буфере
- **WHEN** пользователь во вкладке PR стоит на строке файла в diff-буфере и вызывает `:BBPRBrowse`
- **THEN** в браузере открывается этот файл в диффе PR

### Requirement: Выбор вида объекта аргументом
Команда `:BBPRBrowse pr|file|comment` SHALL открывать объект указанного вида. Если такого объекта в месте вызова нет, команда SHALL ничего не открывать и SHALL показывать сообщение, какого объекта не хватает. `:BBPRBrowse pr` SHALL работать везде, где известен PR.

#### Scenario: PR из diff-буфера
- **WHEN** пользователь в diff-буфере вкладки PR вызывает `:BBPRBrowse pr`
- **THEN** в браузере открывается PR, а не файл

#### Scenario: Комментарий вне комментария
- **WHEN** пользователь в diff-буфере вызывает `:BBPRBrowse comment`
- **THEN** браузер не открывается, и показывается предупреждение, что курсор не на комментарии

### Requirement: Открытие PR
Ссылка на PR SHALL совпадать со ссылкой на PR, которую возвращает Bitbucket. Открывается страница PR в Bitbucket.

#### Scenario: PR из списка
- **WHEN** пользователь в списке PR ставит курсор на PR #103 и нажимает клавишу открытия в браузере
- **THEN** в браузере открывается страница PR #103 того репозитория, к которому PR относится

#### Scenario: Прочий буфер вкладки PR
- **WHEN** во вкладке PR текущий буфер не связан ни с файлом PR, ни с комментарием, и пользователь вызывает `:BBPRBrowse`
- **THEN** в браузере открывается PR вкладки

### Requirement: Открытие комментария
Для комментария под курсором в PR Info или во float-окне с комментариями к строке SHALL открываться страница PR в Bitbucket, на которой показан этот комментарий. Это SHALL работать для комментариев к PR, комментариев к файлам, задач и ответов в треде.

#### Scenario: Комментарий к файлу
- **WHEN** пользователь во float-окне с комментариями к строке ставит курсор на комментарий к файлу и вызывает `:BBPRBrowse`
- **THEN** в браузере открывается этот комментарий в Bitbucket

#### Scenario: Ответ в треде
- **WHEN** курсор стоит на ответе в треде комментария, и пользователь вызывает `:BBPRBrowse`
- **THEN** открывается этот ответ, а не корневой комментарий треда

#### Scenario: PR Info для PR без вкладки
- **WHEN** пользователь открыл PR Info из списка для PR без своей вкладки, поставил курсор на комментарий и вызвал `:BBPRBrowse`
- **THEN** в браузере открывается комментарий этого PR

### Requirement: Открытие файла со строкой
В diff-буфере вкладки PR SHALL открываться дифф PR в Bitbucket на файле из окна. Строка курсора SHALL переводиться в номер строки Bitbucket той же стороны: левая сторона даёт строку исходной версии, правая — строку ветки PR. Если строки нет в диффе PR, SHALL открываться файл без строки с сообщением о причине.

#### Scenario: Строка на правой стороне
- **WHEN** пользователь стоит на правой стороне диффа на строке, которая в ветке PR имеет номер 48, и вызывает `:BBPRBrowse`
- **THEN** открывается дифф PR на этом файле со строкой 48 ветки PR

#### Scenario: Строка на левой стороне
- **WHEN** пользователь стоит на левой стороне диффа на удалённой строке, которая в исходной версии имеет номер 30, и вызывает `:BBPRBrowse`
- **THEN** открывается дифф PR на этом файле со строкой 30 исходной версии

#### Scenario: Строка из target-ветки
- **WHEN** пользователь стоит на строке, которая пришла из влитой target-ветки и отсутствует в диффе PR, и вызывает `:BBPRBrowse`
- **THEN** открывается дифф PR на этом файле без строки, и показывается сообщение, почему строка не передана

#### Scenario: Переименованный файл
- **WHEN** PR переименовывает файл, и пользователь вызывает `:BBPRBrowse` в его диффе на любой стороне
- **THEN** открывается файл под новым именем

### Requirement: Открытие файла из панели Diffview
В панели файлов Diffview вкладки PR команда SHALL открывать дифф PR на файле строки курсора без номера строки. На строке каталога или заголовка панели SHALL открываться PR.

#### Scenario: Строка файла в панели
- **WHEN** пользователь в панели Diffview стоит на строке файла `internal/service.go` и вызывает `:BBPRBrowse`
- **THEN** открывается дифф PR на файле `internal/service.go`

#### Scenario: Строка каталога в панели
- **WHEN** пользователь в панели Diffview стоит на строке каталога и вызывает `:BBPRBrowse`
- **THEN** открывается PR

### Requirement: Нет известного PR
Если в месте вызова PR неизвестен, `:BBPRBrowse` SHALL ничего не открывать и SHALL показывать предупреждение.

#### Scenario: Вкладка без PR
- **WHEN** пользователь в обычной вкладке, не связанной с PR, вызывает `:BBPRBrowse`
- **THEN** браузер не открывается, и показывается предупреждение, что для вкладки нет PR

### Requirement: Клавиши открытия в браузере
Открытие в браузере SHALL быть доступно по клавишам, и каждую из них SHALL можно переопределить или отключить пустой строкой в `setup({ browse = { ... } })`. По умолчанию:
- `<leader>rb` глобально;
- `gx` в PR Info, во float-окне с комментариями к строке и в запасном буфере списка PR;
- `<C-o>` в insert-режиме и `gx` в normal-режиме Telescope-списка PR.

Клавиша SHALL показываться в окне справки `?` тех окон, где она назначена.

#### Scenario: Клавиша по умолчанию в PR Info
- **WHEN** пользователь в PR Info на строке комментария нажимает `gx`
- **THEN** в браузере открывается этот комментарий

#### Scenario: Клавиша в Telescope
- **WHEN** пользователь в Telescope-списке PR в insert-режиме выбирает PR и нажимает `<C-o>`
- **THEN** в браузере открывается выбранный PR, а список остаётся открытым

#### Scenario: Отключение клавиши
- **WHEN** пользователь передаёт в `setup` `browse = { map = "" }`
- **THEN** глобальная клавиша не назначается, а команда `:BBPRBrowse` продолжает работать

#### Scenario: Справка
- **WHEN** пользователь в PR Info нажимает `?`
- **THEN** в окне справки есть строка с клавишей открытия в браузере

### Requirement: Ошибка открытия
Если система не смогла открыть URL, SHALL показываться сообщение об ошибке, содержащее этот URL.

#### Scenario: Нет программы для открытия
- **WHEN** в системе нет программы для открытия ссылок, и пользователь вызывает `:BBPRBrowse`
- **THEN** показывается сообщение об ошибке с URL, который не удалось открыть
