# Proposal

## Why

Из плагина нельзя открыть в Bitbucket ни PR, ни файл в его диффе, ни комментарий. Ссылку приходится искать в веб-интерфейсе вручную, например чтобы показать коллеге место обсуждения, посмотреть то, что плагин не отображает, или проверить, как комментарий выглядит в Bitbucket. Ссылка на PR уже приходит от CLI (`links.self`), а путь, строка и ID комментария плагину известны, поэтому ссылку на любой из этих объектов можно собрать без новых запросов. Пункт «open bb pr in browser» записан в roadmap в `README.md`.

## What Changes

- Новая команда `:BBPRBrowse [pr|file|comment]`. Без аргумента она открывает в браузере самый конкретный объект под курсором: комментарий, затем файл со строкой, затем PR. С аргументом открывает объект указанного вида или сообщает, что такого объекта под курсором нет.
- Клавиши, все настраиваются в `setup({ browse = { ... } })`:
  - `<leader>rb` — глобально;
  - `gx` — в PR Info, во float-окне с комментариями к строке и в запасном буфере списка PR;
  - `<C-o>` (insert-режим) и `gx` (normal-режим) — в Telescope-списке PR.
- Контексты:
  - список PR (Telescope и запасной буфер) — PR под курсором;
  - PR Info — комментарий на строке курсора, иначе PR;
  - float-окно с комментариями к строке — комментарий на строке курсора;
  - diff-буфер вкладки PR (левая и правая стороны) — файл и строка в терминах Bitbucket;
  - панель файлов Diffview — файл на строке курсора;
  - остальные буферы вкладки PR — PR вкладки.
- Открытие URL идёт через `vim.ui.open()` вместо прямого вызова `xdg-open`. Открытие Jira-тикета в браузере и открытие вложений переводятся на тот же способ.
- Пункт «open bb pr in browser» удаляется из roadmap в `README.md`, а команда и клавиши описываются в README.

Копирования ссылки в буфер обмена в этом изменении нет: решено отложить.

## Capabilities

### New Capabilities

- `pr-open-in-browser`: открытие PR, файла PR со строкой и комментария PR в веб-интерфейсе Bitbucket из любого места плагина, где этот объект виден.

### Modified Capabilities

(нет)

## Impact

- `lua/bb_pr/browse.lua` (новый модуль): сборка URL из `pr.links.self` и открытие URL.
- `lua/bb_pr/init.lua`:
  - `default_config`: секция `browse`;
  - `M.setup`: команда `:BBPRBrowse` и глобальная клавиша;
  - `COMMENT_ACTIONS` / `comment_action_specs`: клавиша в PR Info и во float-окне с комментариями;
  - `open_telescope_picker`, `M.open_list`: клавиши в списке PR;
  - открытие Jira-тикета и вложений: переход на общий способ открытия URL.

  В `init.lua` около 198 top-level `local` при пределе Lua в 200, поэтому новых top-level `local` не добавляется.
- `README.md`: описание команды и клавиш, удаление пункта из roadmap.
- Go CLI и запросы к Bitbucket не меняются.
