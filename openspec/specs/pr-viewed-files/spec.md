# pr-viewed-files Specification

## Purpose

Позволяет ревьюеру смотреть большой PR в несколько подходов и в каждый момент видеть, какие файлы PR он ещё не смотрел в их текущем виде.

## Requirements

### Requirement: Состояние просмотра файлов PR
Плагин SHALL хранить для каждого файла отслеживаемого PR признак «просмотрен». Отслеживаемым считается PR в состоянии OPEN, автор которого — не текущий пользователь. Состояние SHALL сохраняться локально, переживать перезапуск Neovim и удаляться вместе с записью просмотра PR. Изначально все файлы PR непросмотрены.

#### Scenario: Первое открытие PR
- **WHEN** пользователь впервые открывает вкладку PR из 12 файлов
- **THEN** все 12 файлов непросмотрены

#### Scenario: Состояние после перезапуска
- **WHEN** пользователь просмотрел 3 файла PR, перезапустил Neovim и открыл тот же PR, а файлы с тех пор не менялись
- **THEN** эти 3 файла просмотрены, остальные — нет

#### Scenario: Свой PR
- **WHEN** пользователь открывает PR, автором которого является он сам
- **THEN** состояние просмотра файлов не ведётся и в панели не отображается

### Requirement: Файл отмечается при показе
Плагин SHALL отмечать файл PR как просмотренный, когда его diff показан во вкладке PR и поверх него не открыто окно PR Info. Способ перехода к файлу не важен: выбор в панели Diffview, переход к следующему или предыдущему файлу, закрытие PR Info.

#### Scenario: Закрытие PR Info при открытии PR
- **WHEN** пользователь открывает PR, PR Info открывается поверх первого файла, и пользователь закрывает PR Info
- **THEN** первый файл отмечен как просмотренный, а пока PR Info был открыт, отметки не было

#### Scenario: Выбор файла в панели
- **WHEN** пользователь выбирает файл в панели Diffview, и его diff показывается, хотя фокус остаётся в панели
- **THEN** файл отмечен как просмотренный

### Requirement: Изменённый файл снова непросмотрен
Плагин SHALL считать просмотренный файл непросмотренным, если содержимое файла в ветке PR отличается от содержимого на момент просмотра. Изменения ветки PR, не затронувшие содержимое файла (другие файлы, rebase, слияние target-ветки), SHALL NOT сбрасывать отметку. Для удалённого в PR файла SHALL сравниваться удаляемое содержимое. Переименованный файл SHALL учитываться под новым путём.

#### Scenario: Автор изменил просмотренный файл
- **WHEN** пользователь просмотрел `src/a.go` и `src/b.go`, затем автор изменил только `src/a.go`, и пользователь снова открывает PR
- **THEN** `src/a.go` непросмотрен, `src/b.go` просмотрен

#### Scenario: Слияние target-ветки
- **WHEN** после просмотра файла автор влил target-ветку в ветку PR, и это не изменило содержимое файла в ветке PR
- **THEN** файл остаётся просмотренным

### Requirement: Ручное переключение отметки
Клавиша переключения (по умолчанию `<leader>rv`, настраивается через `setup`) SHALL в обычном режиме переключать отметку файла под курсором в панели Diffview или текущего файла в diff-буфере. В визуальном режиме в панели клавиша SHALL отмечать все выделенные файлы как просмотренные, если среди них есть непросмотренный, иначе снимать отметку со всех. Выделенная строка каталога SHALL означать все файлы PR внутри этого каталога.

#### Scenario: Снять отметку с текущего файла
- **WHEN** пользователь находится в diff просмотренного файла и нажимает `<leader>rv`
- **THEN** файл становится непросмотренным

#### Scenario: Выделение со смешанным состоянием
- **WHEN** пользователь выделяет в панели три файла, из которых один непросмотрен, и нажимает `<leader>rv`
- **THEN** все три файла просмотрены

#### Scenario: Выделение просмотренных файлов
- **WHEN** пользователь выделяет в панели каталог, все файлы которого просмотрены, и нажимает `<leader>rv`
- **THEN** все файлы каталога непросмотрены

### Requirement: Отображение состояния в панели Diffview
Панель файлов Diffview во вкладке отслеживаемого PR SHALL визуально отличать просмотренные файлы от непросмотренных. Пометка «есть комментарии» SHALL сохраняться независимо от состояния просмотра.

#### Scenario: Панель после частичного просмотра
- **WHEN** в PR 5 файлов, из них 2 просмотрены
- **THEN** в панели 2 файла выглядят как просмотренные, 3 — как непросмотренные, а значок комментариев виден у всех файлов с комментариями

### Requirement: Число просмотренных файлов в PR Info
Окно PR Info для отслеживаемого PR открытой вкладки SHALL показывать число просмотренных файлов из общего числа файлов PR.

#### Scenario: Сводка в PR Info
- **WHEN** пользователь просмотрел 3 файла из 12 и открывает PR Info
- **THEN** окно показывает «Files viewed: 3/12»

### Requirement: PR Info открывается при открытии PR
При каждом успешном открытии вкладки PR плагин SHALL один раз открыть окно PR Info после загрузки комментариев, а при ошибке загрузки — без них. Если активна другая вкладка, PR Info SHALL открыться при возврате во вкладку PR. При переходе к комментарию файла вместо PR Info SHALL открываться окно комментария, а если комментарий не найден — PR Info. Уведомление после открытия SHALL NOT выводиться.

#### Scenario: Открытие PR
- **WHEN** пользователь открывает PR из списка
- **THEN** после загрузки комментариев открывается PR Info со сводкой изменений, отдельное уведомление не выводится

#### Scenario: Комментарии не загрузились
- **WHEN** при открытии PR загрузка комментариев завершилась ошибкой
- **THEN** PR Info всё равно открывается

#### Scenario: Открытие PR с переходом к комментарию файла
- **WHEN** пользователь открывает PR по ссылке на комментарий к файлу
- **THEN** открывается окно этого комментария, а PR Info не открывается

#### Scenario: Другая вкладка активна во время загрузки
- **WHEN** пока загружаются комментарии, пользователь переключился на другую вкладку, а затем вернулся во вкладку PR
- **THEN** PR Info открывается при возврате, один раз
