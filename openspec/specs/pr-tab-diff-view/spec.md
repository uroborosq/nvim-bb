# pr-tab-diff-view Specification

## Purpose

Определяет, что показывают стороны diff во вкладке PR: правая сторона — реальный файл рабочего дерева, с LSP и правкой, левая — вершина target-ветки. Так ревью идёт с полной поддержкой языка.

## Requirements

### Requirement: Правая сторона — файл рабочего дерева
Во вкладке PR правая сторона diff SHALL быть буфером файла рабочего дерева (ветка PR с влитой target-веткой), а не ревизией из git. Это SHALL выполняться для каждого файла PR, кроме удалённых в PR, и при чистом слиянии, и при конфликте.

#### Scenario: Чистое слияние
- **WHEN** пользователь открывает PR, ветка которого сливается с target-веткой без конфликтов, и выбирает в панели файл `pkg/a.go`
- **THEN** правая сторона diff показывает буфер `<repo>/pkg/a.go`, а не `diffview://.../.git/<sha>/pkg/a.go`

#### Scenario: Конфликт слияния
- **WHEN** пользователь открывает PR с конфликтом слияния и выбирает файл с конфликтом
- **THEN** правая сторона diff показывает файл рабочего дерева с маркерами конфликта

### Requirement: LSP на правой стороне
К буферу правой стороны diff во вкладке PR SHALL подключаться LSP, настроенный пользователем для этого типа файла, так же, как при обычном открытии файла. Плагин SHALL NOT предлагать настройку, при которой правая сторона открывается как ревизия из git.

#### Scenario: Go-файл в PR
- **WHEN** у пользователя настроен gopls, и он открывает в PR-вкладке изменённый `.go` файл
- **THEN** к буферу правой стороны подключается gopls, и переход к определению и диагностика работают

#### Scenario: Устаревшая опция в setup
- **WHEN** пользователь передаёт в `setup` `diff_mode = "commits"`
- **THEN** вкладка PR всё равно открывается с файлами рабочего дерева справа

### Requirement: Правка на правой стороне
Буфер правой стороны diff во вкладке PR SHALL быть доступен для редактирования и записи как обычный файл рабочего дерева.

#### Scenario: Правка во время ревью
- **WHEN** пользователь меняет строку в правой стороне diff и выполняет `:write`
- **THEN** изменение записывается в файл рабочего дерева

### Requirement: Левая сторона — вершина target-ветки
Левая сторона diff во вкладке PR SHALL показывать файл в состоянии вершины target-ветки (`origin/<target>`) как ревизию только для чтения.

#### Scenario: Изменённый файл
- **WHEN** пользователь выбирает файл, изменённый в PR
- **THEN** левая сторона показывает содержимое этого файла в `origin/<target>`
